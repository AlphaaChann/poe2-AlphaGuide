# PoE2 AlphaGuide

Interactive leveling checklist for Path of Exile 2 — Acts I–IV.

## Features
- All zones, waypoints, bosses and permanent rewards
- Per-act progress tracking
- Filter by waypoints, bosses, permanent rewards
- Search zones
- Auto-save progress in browser
- Export / Import progress

## Run Locally

### Requirements
- Node.js (https://nodejs.org)

### Setup
```bash
npm install
npm start
```

Open http://localhost:3000

### Dev mode (auto-restart on file save)
```bash
npm run dev
```
